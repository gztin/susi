Spring MVC 4.3.20 / JDK 8 參考語法
此檔僅說明前端 form 的 pageBlocksJson 如何在後端新增、修改與回填畫面，不包含完整 DAO 或資料表實作。

1. 前端 form 欄位

<input type="hidden" name="pageBlocksJson">

前端會以 POST 送出 pageBlocksJson，內容為 pageBlocks 陣列；每個項目包含：
type、sortOrder、content；修改資料可額外帶回 id、cateId。

3. 修改頁查詢並回填

@GetMapping("/editor/update")
public String update(@RequestParam("cateId") Long cateId, Model model) throws IOException {
    // TODO 由 YB_CATE、YB_MAIN、YB_DETAIL 查出資料，並組回前端 pageBlocks 格式。
    List<Map<String, Object>> pageBlocks = pageService.findPageBlocks(cateId);

    ObjectMapper objectMapper = new ObjectMapper();
    String pageBlocksJson = objectMapper.writeValueAsString(pageBlocks);
    model.addAttribute("pageBlocksJson", pageBlocksJson);

    return "update";
}

4. 回傳前端的 pageBlocksJson 格式

[
  {
    "id": 101,
    "cateId": 10,
    "type": "heading",
    "sortOrder": 1,
    "content": { "text": "主標題" }
  },
  {
    "id": 102,
    "cateId": 10,
    "type": "text",
    "sortOrder": 2,
    "content": { "html": "<p>內文</p>" }
  }
]

update.jsp 會將 pageBlocksJson 傳入 window.loadPageBlocks()，依 sortOrder 顯示在編輯器中。
